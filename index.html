นำเข้า / ส่งออกข้อมูล

JSON รองรับเลข 2, 3 และ 4 ตัว; CSV ใช้คอลัมน์ date,category,digits,number,source

แหล่งข้อมูลอัปเดตอัตโนมัติ

เว็บจะลองดึงผลย้อนหลังจาก LotteryChecks สำหรับหวยรัฐบาลไทยและหวยลาวพัฒนาอัตโนมัติ ส่วนประเภทอื่นสามารถใส่ URL JSON สาธารณะที่อนุญาต CORS ได้
