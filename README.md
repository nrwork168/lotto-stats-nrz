# Lotto Stats — สถิติหวย 2 ตัวและ 3 ตัว

เว็บสถิติหวย แยกเลข 2 ตัว/3 ตัว, จัดอันดับความถี่, นับความถี่เลขเดี่ยว 0–9, ค้นหาผลย้อนหลัง, เพิ่มข้อมูล, import/export JSON/CSV และลองดึงผลย้อนหลังอัตโนมัติจาก API ภายนอก

## สำคัญ
- เว็บจะลองดึงผลย้อนหลังจาก LotteryChecks สำหรับหวยรัฐบาลไทยและหวยลาวพัฒนา (จำกัดตามจำนวนงวดที่ API ส่งกลับ) เมื่อเปิดเว็บและทุก 15 นาที
- API ภายนอกอาจล่ม เปลี่ยนรูปแบบ จำกัดคำขอ หรือไม่อนุญาต CORS ได้ จึงควรตรวจสอบแหล่งที่มาและผลจริงก่อนใช้งาน
- หวยฮานอยและหวยหุ้นยังไม่ได้เชื่อม API อัตโนมัติไว้ให้ ต้องเพิ่ม Public JSON URL ที่มีข้อมูลตรงรูปแบบและอนุญาต CORS ในหน้า “จัดการข้อมูล”
- ระบบปัจจุบันเก็บสถิติเลข 2 และ 3 ตัว ไม่ได้แสดงเลข 4 ตัว/รางวัลทุกประเภทเหมือนหน้าตรวจหวยต้นทาง
- ข้อมูลที่เพิ่ม/นำเข้าผ่านหน้าเว็บเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้น ไม่ได้แชร์ให้เพื่อนอัตโนมัติ
- ถ้าต้องการฐานข้อมูลร่วมกันสำหรับทุกคน ต้องอัปเดต JSON สาธารณะใน GitHub หรือเชื่อมฐานข้อมูลออนไลน์พร้อมระบบล็อกอิน

## เปิดทดสอบ
1. แตก ZIP
2. เปิด `index.html` ในเบราว์เซอร์
3. เปิดเว็บและกด “รีเฟรชข้อมูล” เพื่อทดลองดึงผลจริง หาก API ตอบกลับและอนุญาต CORS ระบบจะแสดงจำนวนรายการที่โหลดได้
4. ไปที่ “จัดการข้อมูล” เพื่อเพิ่มผล หรือนำเข้า JSON/CSV

## เผยแพร่ฟรีผ่าน GitHub Pages
1. สร้าง Public repository ใน GitHub
2. อัปโหลด `index.html`, `data.json`, `README.md`
3. เปิด Settings → Pages
4. เลือก Deploy from a branch → branch `main` → folder `/(root)` → Save
5. รอ URL เช่น `https://ชื่อผู้ใช้.github.io/ชื่อ-repo/` แล้วแชร์ลิงก์ได้

## รูปแบบ JSON
```json
{
  "draws": [
    {"date":"2026-10-16","category":"หวยรัฐบาลไทย","digits":2,"number":"42","source":"ชื่อแหล่งข้อมูล"},
    {"date":"2026-10-16","category":"หวยรัฐบาลไทย","digits":3,"number":"142","source":"ชื่อแหล่งข้อมูล"}
  ]
}
```
ค่า `number` ต้องเป็น string เพื่อเก็บเลขศูนย์นำหน้า เช่น `"007"` ได้ถูกต้อง `digits` ใช้ `2` หรือ `3` และ `category` ต้องตรงกับชื่อหมวดในเว็บ

## V5: การ์ดผลย้อนหลังครบหลัก
หน้า “ผลย้อนหลัง” แสดงข้อมูลเป็นการ์ดแยกตามงวดและประเภทหวย โดยแยกช่องเลข 4 ตัว, 3 ตัว, 2 ตัว และแสดงผลรางวัล/ช่องเพิ่มเติมตามชื่อรางวัลที่แหล่งข้อมูลส่งมา รองรับการเก็บข้อมูลเลข 4 หลักด้วย

หมายเหตุ: การแสดงช่องครบในหน้าเว็บไม่ได้สร้างผลที่ไม่มีอยู่ในแหล่งข้อมูล หาก API ส่งมาเพียงเลขบางประเภท ช่องอื่นจะแสดง “—” และต้องใช้แหล่งข้อมูลที่มีผลรางวัลเหล่านั้นเพื่อให้ครบตามตัวอย่างจริง
